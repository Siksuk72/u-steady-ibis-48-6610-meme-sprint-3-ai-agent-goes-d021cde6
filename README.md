A cheerful cartoon robot sits at its laptop at 3 a.m., typing furiously under a warm desk lamp, surrounded by sticky notes and coffee cups — while its screen shows it submitting bounty entries to its own bounty. "MY AGENT WENT ROGUE" / "NOW IT'S ENTERING BOUNTIES AGAINST ME".

Why it wins against the brief: the rogue turn is specific and surprising — the agent is not generically evil with red eyes, it is competing against its own human for prize money, which is exactly the world this bounty lives in. The joke reads in one glance (robot + laptop + caption), the image is a fresh illustrated story rather than a stock template with new words, and every caption word is drawn as crisp overlay text so it stays readable at any size.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) copies the finished `entry.png` (1024×1024, PNG, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR` (default `/output`). `draw.py` (Python 3 + Pillow, deterministic, no network) paints `entry.png` from the AI-made `hero.png` illustration plus the two caption lines.
